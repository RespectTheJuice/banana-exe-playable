## New direction

### Grid means a visible square grid

Do not interpret grid as a generic technical platform.

Use the supplied dark navy square-grid reference:

- navy / near-black background;
- visible square grid lines;
- warm gold/amber energy glow;
- clean, stylized, game-world presentation.

### Grid wake

Before the banana arrives, the grid pulses:

**pulse → pulse → pulse pulse pulse → steady pulse**

This should echo the energy escalation language of the third/final trebuchet interruption without reading as malfunction or failure.

When the banana lands, the pulsing resolves into a stable continuously active glow.

Then ACQUIRE begins.

### Revised beat order

0. GRID WAKE
1. DROP
2. ACQUIRE
3. TARGET
4. MARK
5. COMPLETE
6. HERO

The previous 8.0 s timing is not sacred because GRID WAKE is new. Propose revised timing only after testing the rhythm.

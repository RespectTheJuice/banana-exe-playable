# BANANA.EXE — RTJ Ident Integration Handoff

**Status:** ACTIVE DESIGN EXPLORATION / INCLUDE IN PRODUCT  
**Production:** AN RTJ PRODUCTION

## Purpose

Define how the existing Respect The Juice drink-pouring ident can live inside BANANA.EXE without losing its own identity.

Production principle:

**Project identity first. RTJ integration second.**

BANANA.EXE remains BANANA.EXE. RTJ enters as parent production identity and finishing language, not as a visual takeover.

## Existing ident authority

The existing RTJ ident is valuable because its core already works:

- one glass;
- one pour;
- one reveal;
- distressed RTJ letterforms;
- `RESPECT THE JUICE` subline;
- approximately 7 second runtime;
- clean product-shot framing.

Do not redesign these elements by default.

## Approved BANANA.EXE treatment direction

Current preferred treatment is the **Navy Pour** direction from the Claude Design exploration:

- lift the black field into BANANA.EXE dark navy / blue-black;
- preserve original orange RTJ juice footage for the main ident;
- move `RESPECT THE JUICE` subline into BANANA.EXE warm gold;
- allow one tiny cyan/aqua accent derived from BANANA.EXE system language;
- keep grid language out of the ident except, at most, a near-invisible base/horizon line;
- allow a restrained warm bloom during fill;
- preserve the original RTJ distressed letters;
- do not convert RTJ typography into BANANA.EXE arcade/display typography;
- keep runtime concise.

The strongest current design principle is:

**BANANA.EXE changes the room the ident plays in; it does not redesign the ident itself.**

## Current inclusion decision

The RTJ ident **will be included in BANANA.EXE**. Exact placement and whether it replaces or precedes the current precision-marking intro remain under design review.

A current placement candidate is:

`BANANA.EXE title / PRESS START → RTJ ident → Scene 01`

The PRESS START interaction can unlock browser audio before the ident plays.

Do not duplicate or lengthen the opening until this placement is explicitly locked.

## Banana-specific ident exploration

A stronger BANANA.EXE-specific variant is now worth testing:

1. glass hits the counter;
2. blender hits the counter;
3. banana hits the counter;
4. banana is peeled;
5. banana goes into blender;
6. short blender sound/action;
7. transition into the existing RTJ drink-pouring ident / RTJ reveal.

This may create a more satisfying production intro than the current laser-marking sequence because the action directly produces the RTJ drink identity.

However, this is a **design exploration**, not locked implementation yet.

The risk is runtime and over-sequencing. The sequence should be tested for compression and rhythm before adoption.

## Scope control for banana-specific exploration

Preserve:

- physical counter/drop rhythm;
- clear object-by-object setup;
- banana prep action;
- blender sound as a strong transition cue;
- RTJ ident payoff;
- concise, readable action beats.

Avoid:

- unnecessary hand choreography;
- long food-prep realism;
- excessive close-ups;
- kitchen lore;
- extra dialogue;
- making the setup longer than the payoff earns.

A compressed rhythm is preferred, e.g.:

**glass hit → blender hit → banana hit → peel/drop → BLEND → RTJ ident**

The exact timing must be designed, not guessed.

## Relationship to precision-marking intro

The laser precision-marking intro remains a developed design asset, but it is no longer automatically assumed to be the final opening identity sequence.

Current decision point:

- compare the emotional/readability payoff of the banana/blender/RTJ ident route against the laser-marking route;
- do not implement both as stacked intros unless explicitly approved;
- avoid opening bloat.

If the RTJ ident route wins, preserve useful precision-marking work for another in-world processing moment, explainer, promo, or later update rather than forcing it into the opening.

## Future chapter-transition idea

A short chapter-pour variant remains promising:

- glass acts as a progress bar;
- Part 1 / Part 2 transitions can use partial fills;
- finale earns the full pour and RTJ reveal.

This is future/update material, not required for the immediate opening decision.

## Audio direction

For the main ident:

- preserve source RTJ audio bed where useful;
- physical glass/blender/banana impacts should be tight and tactile if using the banana-specific setup;
- blender should provide one strong sonic transition rather than a long appliance loop;
- RTJ reveal should land with its own existing identity;
- avoid arcade beeps, heavy sci-fi treatment, or excessive system sound.

## Anti-drift

Do not:

- make RTJ look like BANANA.EXE typography;
- cover the ident in grids/HUD/laser graphics;
- turn the orange juice into smoothie in the main Navy Pour version without an explicit variant decision;
- add both laser intro and full banana/blender ident by default;
- let the parent identity erase the project identity;
- let the project identity erase RTJ.

## Next design task

Create a concise Claude Design prototype for the **banana-specific RTJ intro candidate** using the rhythm:

**glass hit → blender hit → banana hit → peel/drop → blend → RTJ ident**

The prototype must answer:

1. total runtime;
2. whether all object beats read without dragging;
3. whether the blender transition feels earned;
4. whether the existing RTJ ident still feels like the payoff rather than a second intro;
5. whether this should replace the laser intro, precede it, or leave the laser for another use.

Do not move to production implementation until this comparison is reviewed.
